# Mail

NeoMutt email setup with mbsync (isync), notmuch, msmtp, and Glow.

## Quick start

```bash
bash mail/setup.sh                                        # install packages + symlinks
cp accounts/example.conf accounts/personal.conf           # define account
nvim accounts/personal.conf                               # fill in 5 fields
pass insert email/gmail                                   # store password
bash mail/gen.sh                                          # generate all configs
mbsync --config ~/.config/isync/mbsyncrc --all && notmuch new   # first sync
neomutt                                                   # launch
```

## Structure

```
mail/
├── accounts/           ← one .conf per account (single source of truth)
│   └── example.conf       template — copy and fill in
├── gen.sh              ← generates tool configs from accounts/*.conf
├── setup.sh            ← one-time: install packages + create symlinks
├── mutt/               → ~/.config/mutt
│   ├── neomuttrc          main config
│   ├── colors.muttrc      Catppuccin Mocha theme
│   ├── keys/binds.muttrc  vim-style keybindings
│   ├── mailcap            MIME handlers
│   ├── scripts/           helper scripts
│   │   ├── mutt-trim      clean quoted text before editing
│   │   └── mutt-viewical  render ICS calendar invites
│   └── accounts/          generated per-account configs + init.muttrc
├── isync/              → ~/.config/isync
│   └── mbsyncrc.example   reference (gen.sh produces the real one)
├── msmtp/              → ~/.config/msmtp
│   └── config.example     reference (gen.sh produces the real one)
├── notmuch/            → ~/.config/notmuch
│   └── default/config     generated by gen.sh (XDG-native path)
└── glow/               → ~/.config/glow
    ├── glow.yml           Glow config
    └── catppuccin-mocha.json  Glow color theme
```

## Keybindings

| Key | Action | Key | Action |
|-----|--------|-----|--------|
| `j/k` | navigate | `gi/gs/gd/gt/ga` | go to inbox/sent/drafts/trash/archive |
| `gg/G` | first/last | `B` | toggle sidebar |
| `l` / `Enter` | open message | `Ctrl-j/k` | sidebar nav |
| `h` | back | `Ctrl-o` | open sidebar folder |
| `O` | sync all mail | `Alt-g` | notmuch search (global) |

## GPG key fetching

GPG can auto-fetch sender public keys via WKD and keyservers. Add to
`~/.gnupg/gpg.conf`:

```
auto-key-locate wkd,keyserver
keyserver hkps://keys.openpgp.org
auto-key-retrieve
```

This makes GPG automatically look up keys when you encrypt to someone:
WKD first (domain-based), then keys.openpgp.org as fallback.

To manually fetch a specific key:

```bash
gpg --locate-keys sender@example.com
```

Set your default signing key in neomuttrc:

```
set pgp_default_key = "YOUR_KEY_ID"
```

GPG keybindings in neomutt:
- `p` in compose menu → PGP menu (sign / encrypt / both / clear)
- `Alt-s` in index/pager → toggle auto-sign on/off

## Display filter (not implemented)

The v1.0.0 config included a `display_filter` that cleaned up emails before
rendering in the pager. It handled:

- **Microsoft Teams meeting invites** — replaced verbose HTML with a clean
  summary showing just the meeting URL
- **Long To/CC headers** — reformatted to one recipient per line for
  readability

The filter was a perl + sed pipeline set via `set display_filter="..."` in
neomuttrc. It was removed for simplicity but can be added back. The original
implementation is at:

  https://github.com/Zenuncl/.dotfiles/tree/v1.0.0/mail/mutt/neomuttrc

Look for the `set display_filter=` line. Copy the full string into your
neomuttrc to enable it.
