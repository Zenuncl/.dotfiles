# Mail

aerc email setup with mbsync (isync), notmuch, msmtp, and Glow.

## Quick start

```bash
bash mail/setup.sh                                        # install packages + symlinks
cp accounts/example.conf accounts/personal.conf           # define account
nvim accounts/personal.conf                               # fill in 5 fields
pass insert email/gmail                                   # store password
bash mail/gen.sh                                          # generate all configs
mbsync --config ~/.config/isync/mbsyncrc --all && notmuch new   # first sync
aerc                                                      # launch
```

## Structure

```
mail/
├── accounts/           ← one .conf per account (single source of truth)
│   └── example.conf       template — copy and fill in
├── gen.sh              ← generates tool configs from accounts/*.conf
├── setup.sh            ← one-time: install packages + create symlinks
├── aerc/               → ~/.config/aerc
│   ├── aerc.conf          main config (UI, filters, compose, viewer)
│   ├── binds.conf         vim-style + Gmail keybindings
│   ├── accounts.conf      generated per-account config
│   ├── accounts.conf.example  reference for manual setup
│   ├── stylesets/
│   │   └── catppuccin-mocha   Catppuccin Mocha theme
│   └── filters/
│       └── ical           ICS calendar invite renderer
├── isync/              → ~/.config/isync
│   └── mbsyncrc.example   reference (gen.sh produces the real one)
├── msmtp/              → ~/.config/msmtp
│   └── config.example     reference (gen.sh produces the real one)
├── notmuch/            → ~/.config/notmuch
│   └── default/config     generated by gen.sh (XDG-native path)
└── glow/               → ~/.config/glow
    ├── glow.yml           Glow config
    └── catppuccin-macchiato.json  Glow color theme
```

## Markdown compose

aerc supports converting markdown to HTML via `[multipart-converters]`.
In compose review mode, run `:multipart text/html` to generate an HTML
version from your markdown body. Requires `pandoc`.

## GPG key fetching

GPG can auto-fetch sender public keys via WKD and keyservers. Add to
`~/.gnupg/gpg.conf`:

```
auto-key-locate wkd,keyserver
keyserver hkps://keys.openpgp.org
auto-key-retrieve
```

This makes GPG automatically look up keys when you encrypt to someone:
WKD first (domain-based), then keys.openpgp.org as fallback.

To manually fetch a specific key:

```bash
gpg --locate-keys sender@example.com
```

### Per-account PGP in aerc

Add to the account section in `accounts.conf` (or `accounts/*.conf` + re-run gen.sh):

```ini
pgp-auto-sign = true
pgp-self-encrypt = true
pgp-key-id = YOUR_KEY_ID
```

In aerc compose, use `:sign` and `:encrypt` commands.

## Notmuch search

aerc uses the maildir backend with mbsync for sync. For notmuch search,
`Alt-g` opens an embedded terminal with `notmuch search`.

For deeper notmuch integration, switch `source` in accounts.conf from
`maildir://` to `notmuch://` — this enables native `:search` with notmuch
queries but requires a query-map file per account.
